# Pre-call Bank Marketing Response Prediction

This project is about predicting whether a bank customer is likely to subscribe to a term deposit before receiving a marketing call using Machine Learning. A term deposit account is an account where customers keep money for a fixed period, usually to earn interest.

## Purpose
The main purpose is to develop a Machine Learning system that studies customer information and predicts whether a customer is likely to subscribe to a term deposit. It helps banks identify potential customers and improve the efficiency of their marketing campaigns.

I designed a Machine Learning workflow using the UCI Bank Marketing dataset structure. The project compares Logistic Regression, Random Forest, Histogram Gradient Boosting, and Prevalence Baseline to identify the best-performing model.

## Setup
This projects require Python 3.11 or later.

## Result
The initial demonstration showed promising performance on simulated data, with 90% accuracy and an 81.2% F1-score for the calibrated model. However, validation on the actual UCI dataset is still required.

Overall, the project demonstrates how Machine Learning can be used to support smarter, data-driven decisions in banking.
